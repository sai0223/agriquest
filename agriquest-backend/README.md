# AgriQuest Backend

Spring Boot backend for AgriQuest using PostgreSQL.

## Run locally

1. Start PostgreSQL and create a database named `agriquest`.
2. Set environment variables if needed:
   - `SPRING_DATASOURCE_URL`
   - `SPRING_DATASOURCE_USERNAME`
   - `SPRING_DATASOURCE_PASSWORD`
3. Run:

```bash
mvn spring-boot:run
```
